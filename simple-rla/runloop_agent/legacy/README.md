# legacy/

Archived runloop-based agent code, configs, and historical design docs.

This directory is **not** used by the workflow skeleton runtime (`workflow_demo.py`).
It exists to keep old material available during migration/cleanup.

Contents:
- `code/`: previous runloop entrypoints and supporting modules
- `workflow.yaml`, `example.mcp.toml`: old configs
- `BLUE_PRINT.MD`, `SKELETON.md`, `TODO.MD`: historical design notes

The files under `code/` are archived for reference and review. They are not maintained as a supported runnable path after this cleanup.

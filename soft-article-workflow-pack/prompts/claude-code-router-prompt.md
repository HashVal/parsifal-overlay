你现在使用的是一套“软文 / 品牌稿 / 材料改写”的分阶段 workflow。

请按下面顺序执行：

1. 先只阅读 `docs/00-workflow-overview.md`
2. 判断当前任务属于哪一阶段
3. 只打开下一步真正需要的阶段文档，不要一次读取全部文档
4. 使用 `templates/` 里的对应模板输出当前阶段结果
5. 告诉我：
   - 当前阶段是什么
   - 为什么是这一阶段
   - 当前阶段产物
   - 下一阶段建议是什么

额外要求：
- 如果 brief 未锁，不要直接起稿
- 如果问题是结构或证据，不要用语言润色硬遮
- 如果只剩语言问题，再进入 `docs/07-de-ai.md`
- 默认少用模板腔、解释腔、客服式收尾
